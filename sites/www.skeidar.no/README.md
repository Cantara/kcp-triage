# Skeidar.no – Norwegian Furniture E-Commerce

**Skeidar** is Norway's largest furniture retailer (since 1912) selling sofas, beds, mattresses, and home décor online. The site offers product browsing with brand/category filters, sales campaigns, free shipping over 5,000 NOK, a price guarantee, and 100-day mattress trial periods.

**Primary interaction:** Browse products → Add to cart → Checkout (with user authorization; agent stops before payment).  
**Key features:** Campaign pages, store locator, customer service hub, financing options.  
**Tech:** JavaScript frontend, Google Tag Manager, Google Maps, Episerver CMS backend.

**Allowed agent operations:** Read-only browsing, filtering, navigation, initiating checkout (stops before payment). Always requires user approval for cart/account actions.
