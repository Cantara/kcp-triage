# Skill: Navigate Samordna opptak

## Overview
Move through Samordna opptak site sections, access different application pathways, and locate key informational pages.

## Key Navigation Points

### From Home (`/`)
- **Left/Header Menu:**
  - "Forsiden" (Home)
  - "Søk universitet og høgskole" (Apply to Universities/Colleges)
  - "Søk fagskole" (Apply to Vocational Schools)
  - "Informasjonsvideoer" (Info Videos)
  - "Om" (About)
  - "Information in English"
- **Quick Links:**
  - "Til søkerportalen" (To Application Portal) — external link
  - "Søk universitet og høgskole" card
  - "Søk fagskole" card
  - "Vitnemål" (Transcripts) card
  - "Jeg har søkt - hva skjer nå?" (After Application) card
  - "Søkertall og poenggrenser" (Statistics) card

### Within Each Section
- **Universities/Colleges** (`/universitet-og-hogskole/`):
  - Tabs/sections: Before You Apply, When You Apply, After You Apply, Deadlines 2026
  - Key pages: Slik søker du, Opptakskrav, Opptakskvoter, Poengberegning, Poenggrenser
- **Vocational Schools** (`/fagskole/`):
  - Similar structure: Before, When, After applying, Deadlines
  - Key pages: Slik søker du, Opptakskrav, Poengberegning
- **Videos** (`/filmer/`):
  - Four main topics: How to Apply, What Happens After, Upload Documentation, Prioritizing Programs
- **About** (`/om/`):
  - Subsections: What is Samordna opptak, Contact, Statistics, Privacy, Accessibility

### Language Toggle
- Norwegian main site: `/`
- English: `/english/` (includes General Requirements, Language Requirements, Deadlines, Tuition, Postgraduate Info)

## Search Function
- Search box present in header
- Searches site content across all sections
- Useful for finding specific topics (e.g., "poenggrenser", "tidsfrister", "vitnemål")

## External Portal Access
- **Direct Link:** https://sok.samordnaopptak.no/#/
- **From Any Page:** "Til søkerportalen" button in header/footer
- **Study Overviews:** Links embedded on application guide pages:
  - Universities/Colleges: https://sok.samordnaopptak.no/#/admission/18/studies
  - Vocational Schools: https://sok.samordnaopptak.no/#/admission/19/studies

## Breadcrumb Trail
- Each page shows breadcrumb navigation (e.g., "Forsiden > Søk universitet og høgskole > Slik søker du")
- Click to move up the hierarchy

## Common Workflows

### Find Application Deadlines
1. Home → "Søk universitet og høgskole" OR "Søk fagskole"
2. Look for "Tidsfrister 2026" section
3. Or use search: type "tidsfrister"

### Find Admission Requirements
1. Home → Choose pathway (Uni/College OR Vocational)
2. Look for "Opptakskrav" section
3. Or search: "opptakskrav"

### Find Point Calculation Rules
1. Home → "Søk universitet og høgskole"
2. Scroll to "Poengberegning" or "Poenggrenser"
3. Or navigate to `/universitet-og-hogskole/poengberegning/`

### Access English Information
1. Home → Click "Information in English" (top right or in menu)
2. Or navigate directly to `/english/`

### Get Help After Applying
1. Home → Click "Jeg har søkt - hva skjer nå?" card
2. Or navigate to `/jeg-har-sokt-hva-skjer-na.html`

## Tips
- Site structure mirrors the application journey: "Before You Apply" → "When You Apply" → "After You Apply"
- External portal (søkerportalen) is clearly separated; this site is informational only
- Most pages include a "Next Steps" or "Related Links" section
- Statistics and historical data are in `/om/tall-og-statistikk/`
