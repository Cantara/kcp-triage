# Skill: Find Study Programs

## Overview
Search and filter study program offerings across Norwegian universities, university colleges, and vocational schools.

## Access the Study Program Databases

### Universities & University Colleges
- **Direct Link:** https://sok.samordnaopptak.no/#/admission/18/studies
- **From Main Site:** Navigate to `/universitet-og-hogskole/` → Click "Se studieoversikten" (View Study Overview)
- **Or:** Home → "Søk universitet og høgskole" → Look for study search link

### Vocational Schools (Fagskole)
- **Direct Link:** https://sok.samordnaopptak.no/#/admission/19/studies
- **From Main Site:** Navigate to `/fagskole/` → Click "Se studieoversikten" (View Study Overview)
- **Or:** Home → "Søk fagskole" → Look for study search link

## Using the Study Search (Studieoversikten)

The study search is hosted in the external portal but accessible to non-logged-in users for browsing.

### For Universities & University Colleges

**Filters typically available:**
- **Institution:** Filter by university or university college name
- **Study Level:** Bachelor, Master, Specialist, PhD (where applicable)
- **Program Type:** Full-time, part-time
- **Language:** Norwegian, English, other
- **Keyword:** Search by program name (e.g., "Computer Science", "Medicine", "Business")

**Program Information Shown:**
- Program name (English and Norwegian)
- Degree type and length (e.g., "Bachelor, 3 years")
- Institution
- Study language
- Application code (needed when applying)
- Point border (poenggrense) if available
- Link to full program description on institution's website

### For Vocational Schools

**Filters typically available:**
- **School/Institution:** Filter by vocational school
- **Program Name:** Search by title
- **Keyword:** General search
- **Location** (if applicable)

**Program Information Shown:**
- Program name
- Duration
- School
- Application code
- Point border (if applicable)
- Brief description

## Detailed Program Information

The Samordna opptak database provides basic details, but for complete information:

1. **Within Study Search:** Usually a link to the institution's detailed program description
2. **Institution Website:** Click through to the full program page
3. **Key Details to Look For:**
   - Admission requirements (specific prerequisite courses)
   - Language of instruction
   - Tuition fees (for non-EU/EEA students)
   - Program content and specializations
   - Internship or practical components
   - Career outcomes
   - Contact details for program advisor

## Common Searches

### Find All Programs at a Specific Institution
1. Go to study search (uni or fagskole)
2. Filter by institution name
3. Browse all programs offered
4. Compare admission requirements and point borders

### Find Programs in a Specific Field
1. Use keyword search (e.g., "Engineering", "Nursing", "Business")
2. Review results
3. Filter by institution or language if needed
4. Check point borders to assess competitiveness

### Find English-Taught Programs
1. Go to study search (universities)
2. Filter by language: "English"
3. Review all English-language offerings
4. Useful for international applicants

### Find Vocational Programs (2-3 Year Programs)
1. Go to vocational school study search (fagskole)
2. Browse by institution or keyword
3. Note application codes and point borders

### Find Master's Programs
1. Go to university study search
2. Filter by level: "Master"
3. Note: Some master's programs are not in Samordna opptak; check institution websites separately

## Interpreting Program Information

### Application Code (Oppgavekode or Studiekode)
- Used when filling out your application in the portal
- Essential: Write down the correct code before applying
- Each program has a unique code
- Double-check when entering in your application form

### Poenggrense (Point Border)
- Minimum score needed for admission to that program
- Varies by competition level
- Shown for previous years and current year
- Use to gauge competitiveness of your target program
- If your calculated points exceed poenggrense, you likely will be admitted

### Study Language
- Indicates whether instruction is in Norwegian or English
- Important for international applicants
- Some programs may have mixed-language components

### Degree Type
- **Bachelor:** 3 years typical, open to upper secondary graduates
- **Master:** 2 years typical, requires bachelor's degree
- **Specialist:** Higher qualification in specific field
- **PhD:** Research degree, limited availability

## Tips for Effective Search

1. **Start with keywords** relevant to your interests
2. **Check point borders** for programs you're considering
3. **Filter by language** if you have language preferences
4. **Verify institution** (make sure it's the one you want)
5. **Click through to institution website** for full details on:
   - Specific admission requirements (e.g., certain prerequisite courses)
   - Program structure and specializations
   - Tuition fees for international students
   - Housing and student life information
6. **Note the application code** before you begin your application
7. **Compare point borders** across similar programs to understand competition

## After Finding Programs

1. **Make a list** of 5–10 programs you're interested in
2. **Prioritize them** (you'll rank them in your application)
3. **Check deadlines** at `/universitet-og-hogskole/tidsfrister` or `/fagskole/tidsfrister`
4. **Verify admission requirements** at institution websites
5. **Apply via the portal:** https://sok.samordnaopptak.no/#/
6. **Rank your choices** in order of preference during application

## Search Tips by Program Type

### Popular Programs (e.g., Medicine, Law, Psychology)
- **Expect high point borders**
- **Competition very strong**
- Filter by these programs to see historical cut-offs

### Niche Programs (e.g., Specific engineering specializations)
- **Often lower point borders**
- **Less competition**
- Good options if interested in the field

### English-Taught Programs
- **May be more available** in larger institutions
- **Designed for international applicants**
- Good option if Norwegian language proficiency is an issue

### Vocational Programs (Fagskole)
- **Shorter duration (2–3 years)**
- **Practical focus**
- **Often lower point borders** than universities
- Direct entry to workforce
