# Samordna opptak (Norwegian Universities and Colleges Admission Service)

**Type:** Government education information portal  
**Primary Function:** Centralized admissions guidance and coordination for Norwegian higher education  
**Interaction:** Read-only informational site with links to external application portal  
**Content:** Application procedures, deadlines, admission requirements, point calculations, statistics, videos  
**Languages:** Norwegian (primary), English (secondary)  
**External Portal:** https://sok.samordnaopptak.no/#/ (separate single-page application for actual application submission)  
**Tech Stack:** Vortex CMS  

Provides comprehensive guidance for prospective students applying to Norwegian universities, university colleges, and vocational schools. No direct application submission or authentication on main domain.
