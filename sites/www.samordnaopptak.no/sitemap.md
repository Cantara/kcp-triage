# Samordna opptak — Site Structure & Navigation

## Main Sections

### Home
- **URL:** `/`
- **Content:** Landing page, latest news, links to key resources
- **Key Links:** Apply to uni/college, apply to vocational school, videos, info in English, portal link

## External Systems (Not on Main Domain)

### Application Portal (Søkerportalen)
- **URL:** `https://sok.samordnaopptak.no/#/`
- **Features:** User registration, application submission, study selection, document upload, status tracking
- **Accessed Via:** "Til søkerportalen" links throughout main site
- **Study Programs:**
  - Universities/Colleges: `https://sok.samordnaopptak.no/#/admission/18/studies`
  - Vocational Schools: `https://sok.samordnaopptak.no/#/admission/19/studies`

## Navigation Flow

1. **First-time visitor:** Home → "Skal du søke studier?" prep guide → Choose uni/college OR vocational school → Read requirements, deadlines, how-to guides → Links to external portal
2. **Specific inquiry:** Use main navigation or search → Find relevant section (e.g., point borders, requirements) → Often ends with link to søkerportalen or contact info
3. **After application:** `/jeg-har-sokt-hva-skjer-na.html` → Timeline and next steps
4. **International applicant:** `/english/` → General/language requirements → External links to Study in Norway and tuition info
