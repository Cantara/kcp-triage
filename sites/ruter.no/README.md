# Ruter.no — Oslo & Akershus Public Transit Portal

Official site for Ruter AS, the public transit authority serving the Oslo/Akershus region with buses, metro (T-bane), trams, and boats.

**Type:** Government / Public Service Portal  
**Primary Features:** Trip planning, real-time status, ticket info, school transport, help & contact  
**Tech:** Astro + Sanity CMS  
**Interaction:** Read-only (info/discovery); optional user login at minside.ruter.no  
**Key Subdomains:** reise.ruter.no (journey planner), minside.ruter.no (user portal), kontakt.ruter.no (contact form)

Use this guide to navigate the site, plan journeys, understand ticket options, and locate help resources.
