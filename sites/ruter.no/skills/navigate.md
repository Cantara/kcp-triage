# Skill: Navigate Ruter.no

## Overview
Ruter.no is organized into clear sections accessible from the main navigation bar. This skill covers how to find information, move between sections, and access key resources.

## Main Navigation Bar
The top navigation contains these links:
- **Reisesøk** → https://reise.ruter.no/ (journey planner SPA)
- **Trafikkstatus** → https://ruter.no/trafikkstatus (current disruptions)
- **Planlegg reise** → https://ruter.no/planlegg-reise (trip planning hub)
- **Om våre billetter** → https://ruter.no/om-vare-billetter (tickets & fares)
- **Skoleskyss** → https://ruter.no/skoleskyss (school transport)
- **Få hjelp og kontakt** → https://ruter.no/fa-hjelp-og-kontakt (help & support)
- **Om oss** → https://ruter.no/om-oss (about Ruter)
- **Logg inn** → https://minside.ruter.no/ (user account portal)

## Finding Content

### Homepage (https://ruter.no/)
Start here for quick access to:
- Journey search input field (links to reise.ruter.no)
- Traffic status summary
- Ticket purchase guide
- Tourist information
- Contact section

### By Topic
**Trip Planning:**
1. Visit https://ruter.no/planlegg-reise
2. Sections include:
   - Reiseplanlegger (external link to reise.ruter.no)
   - Trafikkstatus
   - Rutetabeller og linjekart (downloadable route maps)
   - Ruter-appen (mobile app info)

**Tickets:**
1. Visit https://ruter.no/om-vare-billetter
2. Choose ticket type:
   - Enkeltbillett (single trip)
   - Periodebillett (daily/weekly/monthly/yearly passes)
   - Turistbillett (tourist passes, Oslo Pass)
3. Click "Se billettpriser" or "Her kjøper du billett" for details

**School Transport:**
1. Visit https://ruter.no/skoleskyss
2. Choose region:
   - Akershus (Ruter manages)
   - Oslo (Oslo kommune manages)

**Help:**
1. Visit https://ruter.no/fa-hjelp-og-kontakt
2. Find contact info, phone number, contact form
3. Browse FAQs by topic
4. Submit feedback via https://kontakt.ruter.no/

## Navigating Between Pages

### Breadcrumbs
Detail pages show breadcrumb trails:
- Example: "Hjem > Om våre billetter > Enkeltbillett"
- Click any breadcrumb to jump back

### Section Links
Each section homepage has card links to subsections:
- Clicking a card title navigates to the detail page
- "Chevron right" (→) icons indicate clickable links

### Footer Links
Bottom of page contains:
- Company info (Om Ruter)
- Links to external partners (Sporveien, Oslo kommune)
- Privacy policy, cookie settings, accessibility statement

## External Resources

### Journey Planner (Separate Domain)
- **URL:** https://reise.ruter.no/
- **Access:** Click "Reisesøk" in nav or "Planlegg din reise" button on homepage
- **Purpose:** Real-time trip search, departures, route suggestions

### User Portal (Separate Domain)
- **URL:** https://minside.ruter.no/
- **Access:** Click "Logg inn" in top-right
- **Purpose:** Manage saved trips, account settings, travel history

### Contact Form (Separate Domain)
- **URL:** https://kontakt.ruter.no/no/transportmiddel-og-stoppested
- **Access:** Click "Gi oss tilbakemelding" or "Kontakt oss"
- **Purpose:** Submit incident reports, feedback, lost & found claims

## Mobile/App Navigation
The site is responsive. Mobile users see:
- Hamburger menu (☰) in top-left
- Touch-friendly navigation items
- Same content hierarchy as desktop

## Tips
1. **Reisesøk is the key tool** — always recommend https://reise.ruter.no/ for trip planning
2. **Language is Norwegian** — main site is in Norwegian (Bokmål)
3. **Separate domains handle complex tasks** — authentication (minside.ruter.no), journey planning (reise.ruter.no), feedback (kontakt.ruter.no) are on separate subdomains
4. **Check Trafikkstatus first** — before giving route advice, check current disruptions
5. **Skoleskyss is region-specific** — Akershus handled by Ruter; Oslo by Oslo kommune
